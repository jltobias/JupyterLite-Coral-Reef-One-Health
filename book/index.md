# Coral Reef One Health

![Coral Reef One Health: a tropical coastline, reef fish, and corals connected by a shared ocean.](../assets/reef-splash.png)

**Map the reef. Explore the evidence. Connect ecosystems and people.**

This open learning resource brings together satellite reef mapping, field observations, and a One Health perspective. Read the lessons here, then run the companion notebooks in [JupyterLite Lab](https://jltobias.github.io/JupyterLite-Coral-Reef-One-Health/lite/lab/index.html). Python runs in your browser; learners do not need an account or a local Python installation.

## Start exploring

1. Compare the [three global mapping initiatives](mapping-initiatives.md): their purposes, strengths, and limits.
2. Explore [One Health connections](one-health.md) between reef habitats, marine animals, and coastal communities.
3. Open **01-reef-mapping.ipynb** in Lab to inspect a small, cited resource catalogue.
4. Open **02-one-health.ipynb** to compare fictional monitoring sites and test how indicator weights affect a teaching score.
5. Explore [research tools and next steps](research-resources.md) for external monitoring, field-survey, image-annotation, and biodiversity resources.

The notebooks use bundled JSON and CSV files and Python's standard library. They do not download reef datasets, require API credentials, or depend on external mapping services. The Python runtime is downloaded on first use, so an internet connection is needed to start Lab.

## What is included?

| Resource | What you can do |
| --- | --- |

The splash image is an AI-generated illustration, not an observation of a real reef. External datasets retain their providers' terms; see [references and data use](references.md).
